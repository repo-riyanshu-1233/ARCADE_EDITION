🎮 Arcade Edition

Arcade Edition is a web-based gaming hub that brings multiple browser games together in one place.

Instead of visiting separate websites for every game, users can access all the available games directly from the Arcade Edition platform.

live web - https://arcade-edition.onrender.com

🌐 Multiplayer

Several games in Arcade Edition support real-time online multiplayer.

Players can create or join a room using a randomly generated room code.

The multiplayer games use PeerJS / WebSocket-based communication to synchronize gameplay between connected players.

🤖 AI Gaming

Games with AI mode allow users to play without requiring another player.

The AI handles its turns automatically and provides a single-player gaming experience.

👥 Pass & Play

Players can enjoy supported games together on the same device.

No online room or multiplayer connection is required for this mode.
